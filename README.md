# Vasuta Digital SMM

Static, responsive website for Vasuta Digital SMM. Live at https://pratikstb.github.io/vasutadigitalsmm.github.io/

## Files
- `index.html`, `style.css`, `script.js` — the site
- `assets/` — favicon and the 1200x630 social preview image (`og-image.png`)
- `sitemap.xml` — submit this in Google Search Console

## Publish on GitHub Pages
1. Commit and push to `main`.
2. GitHub → repository Settings → Pages → Deploy from branch → `main` → `/ (root)`.

## Before going further
- Replace the demo project visuals with your own work as it becomes available.
- Do not publish fabricated testimonials or results.
- If you move to a custom domain, update the canonical, Open Graph, JSON-LD and `sitemap.xml` URLs in `index.html` and `sitemap.xml`, and add a `robots.txt` at the domain root.
