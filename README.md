# Vasuta Digital SMM

Static, responsive website for Vasuta Digital SMM.

## Publish on GitHub Pages
1. Put `index.html`, `style.css`, `script.js` and `assets/` in the root of `PratikSTB/vasutadigitalsmm.github.io`.
2. Commit and push.
3. GitHub → repository Settings → Pages → Deploy from branch → `main` → `/root`.
4. The site will be available on the repository's GitHub Pages URL.
